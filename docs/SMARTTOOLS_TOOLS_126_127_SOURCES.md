# Tools 126–127 source and scope update (2026-10-26)

Tools 126 and 127 are deterministic training reference calculators. Tool 126 uses heuristic performance comparisons and Tool 127 uses user-reported readiness factors; neither is a medical diagnosis or external AI assessment.

Their v6 schemas now enforce finite bounded numeric inputs and reject unknown fields. Scores and readiness bands are educational indicators with explicit disclaimers.
