# Tool 103 source and scope update (2026-10-26)

Tool 103 is an educational CKD-EPI 2021 and fluid-balance calculation. It is not a diagnosis, hydration prescription, or clinical triage. The input schema now requires finite bounded values, integer age, and rejects unknown fields.

The adapter no longer reports an artificial confidence score or an assumed universal reference range; the result remains an estimate requiring laboratory and clinician context.

Browser, accessibility, live persistence, and clinical validation remain unverified.
