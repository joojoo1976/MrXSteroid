# Tool 101 source and scope update (2026-10-26)

Tool 101 is an educational first-order elimination timeline using published half-life assumptions. It must not be used as an AAS/SARM transition protocol, dosing schedule, prescription, or recovery promise.

The input schema now rejects unknown fields and requires finite bounded duration values. The adapter reports unassessed data quality instead of an artificial confidence score.

Because the tool references controlled substances and endocrine recovery, owner scope and source review remain required before rollout.
