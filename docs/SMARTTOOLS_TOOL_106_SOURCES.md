# Tool 106 source and scope update (2026-10-26)

Tool 106 is a deterministic educational glycogen/water reference model. It must not be used as a peak-week protocol, dehydration plan, carbohydrate prescription, or medical decision tool.

The schema now enforces finite bounded values, integer day counts, and rejects unknown fields. The adapter no longer reports an artificial confidence score; model output remains an estimate with unassessed data quality.

Owner scope review is still required before rollout because the output concerns nutrition and fluid balance.
