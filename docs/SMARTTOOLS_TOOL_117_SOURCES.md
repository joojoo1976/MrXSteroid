# Tool 117 source and scope update (2026-10-26)

Tool 117 is a deterministic reference calculator for intra-workout carbohydrate, fluid, sodium, and amino-acid quantities. It is not a supplement prescription, medical hydration plan, or guarantee of performance.

The schema now enforces finite bounded values, strict nested intake objects, and rejects unknown fields. Outputs must be read as educational reference ranges based on user-entered session parameters.
