# Tool 129 source and scope update (2026-10-26)

Tool 129 is a deterministic weekly training scenario generator from user-selected goals, experience, equipment, readiness, and limitations. It is not an AI coach, medical plan, or substitute for qualified training supervision.

The v6 schema now enforces finite bounded values, integer session counts, trimmed equipment labels, and rejects unknown fields. Output volume/intensity are model labels and should not be treated as personalized prescriptions.
