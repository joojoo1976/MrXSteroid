# Tool 107 source and scope update (2026-10-26)

Tool 107 is a deterministic educational phase timeline. It is not a peak-week manipulation protocol, dehydration plan, sodium plan, medication plan, or medical triage tool. The dehydration tier is a model label based on the user-entered hydration status, not a diagnosis.

The schema now enforces finite bounded values, integer days, and rejects unknown fields. The adapter reports unassessed data quality rather than an artificial confidence score.

Owner scope review is required before rollout because the output concerns contest preparation and fluid balance.
