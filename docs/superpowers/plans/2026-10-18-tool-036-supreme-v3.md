> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild tool-036 as a Dark-OS "SUPREME V3" surface (weekly drag-drop calendar + body map + auto rotation + volume guard + comfort tracker + live mg/wk + Gantt + PDF) served directly with no feature flag.

**Architecture:** The pure calculation layer already exists in `lib/tools/engines/tool-036-injection-schedule.ts` (rotation, zones, comfort, gantt, FHIR). V3 adds a small set of new pure helpers there, then a new UI shell reusing it. **Tech Stack:** Next.js 15 App Router, React 19, Tailwind v4, Zod, vitest (node + jsdom projects), `@dnd-kit/core`+`@dnd-kit/sortable` (lazy), `recharts` (already lazy).

**Spec:** User request 2026-10-18 (Dark OS, 7-column drag-drop calendar, 8-site body map, auto rotation, volume guard badge+tooltip, comfort tracker, next-injection countdown, real compounds, live mg/wk, this-week Gantt, PDF export, bundle <150 kB, 310/310, Compiled, push main + HTTP 200 LIVE, no flag).
