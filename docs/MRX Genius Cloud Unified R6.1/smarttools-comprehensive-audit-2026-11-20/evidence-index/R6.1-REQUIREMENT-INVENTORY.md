## 1. Purpose and method

This file is the **requirement inventory** companion to `../AUDIT-METHODOLOGY.md`. It records, without rewriting them, the original R6.1 requirements that were read from the governing sources, their applicability rule, the tools/domains to which they bind, and the authoritative atomic-denominator source for each of the 29 tools. It deliberately does **not**:

- invent a denominator where the authoritative atomic source cannot be recovered (`00-PLAN-AND-AUDIT-STANDARD.md:32`);
- promote the 18-row operational closure grid to an official per-tool denominator (`W2-CANONICAL-DENOMINATOR-INVENTORY.md:12`, `:40`);
- re-award any historical E3/E4/E1 as a fresh result at the fixed baseline (`W2-AUDIT-DECISION-REGISTRY.md:27-33`; `TOOL-034-INDIVIDUAL-DEVELOPMENT-AUDIT.md:244`; `TOOL-040-INDIVIDUAL-DEVELOPMENT-AUDIT.md:134`);
- assert a tool decision, completion percentage, or owner approval.

The per-tool audit mapping template required by the audit standard is `Original requirement ID | Audit matrix ID | Canonical requirement | Applicability | Evidence | Difference/missing mapping` (`00-PLAN-AND-AUDIT-STANDARD.md:32`). This inventory supplies the **original requirement ID/source**, the **canonical requirement**, and the **applicability/denominator** columns. It does not fabricate the per-atomic `Audit matrix ID` or `Evidence` columns; those belong to a later, separately authorised per-tool audit and must be derived from actual test output.
