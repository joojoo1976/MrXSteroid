### عقد القدرة الصادق - Capability Truthfulness Contract (الزامي لكل اداة وكل ميزة AI)
لكل اداة ولكل ميزة AI، يجب ان يعلن النظام صراحة في الواجهة وفي السجل:
1. **CAN - ماذا نستطيع:** ما تحسبه الاداة فعلا، بالصيغة والمدخلات والنطاق المختبر.
2. **CANNOT - ماذا لا نستطيع:** ما لا تحسبه، وما لا تشخصه، وما لا توصي به، وما يتطلب طبيبا او مختبرا او قياسا حقيقيا.
3. **SOURCES - من اين جاءت البيانات:** كل مصدر: الاسم + الناشر + تاريخ النشر + تاريخ المراجعة + مستوى الدليل + رابط او مرجع قابل للتحقق. بلا مصدر = بلا اجابة طبية.
4. **WHY - لماذا اصدرت النتيجة:** خطوات الاستدلال + الصيغة المستخدمة + المدخلات الفعلية + الافتراضات + عدم اليقين. النتيجة بلا سبب مرفوضة.
5. **COST - ما التكلفة:** تكلفة الطلب (Tokens + وقت + مال تقديري) + الميزانية المتبقية + ما يحدث عند السقف (Fallback حتمي).
6. **STOP - كيف نوقفها:** زر/مفتاح الايقاف + مالك الايقاف + زمن التفعيل + ما يظهر للمستخدم بعد الايقاف.
7. **RESTORE - كيف نستعيد النظام:** خطة الاستعادة + RPO/RTO + اخر Drill ناجح + ماذا يحدث لبيانات المستخدم اثناء الفشل.
