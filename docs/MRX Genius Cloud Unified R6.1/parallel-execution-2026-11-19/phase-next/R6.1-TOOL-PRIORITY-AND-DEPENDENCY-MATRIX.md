## 1. Nature of the score

The score below is a **transparent planning heuristic for sequencing locally authorizable work**. It is **not** a similarity score, **not** a measure of "how close to Tool 039", and **not** a completion or 100%-verification claim. It deliberately does not reward a high recorded percentage when the remaining rows are external gates. No tool is owner-accepted, and no score grants authorization.

### Scoring inputs (all evidence-bounded)

| Input | Meaning | Values |
|---|---|---|
| **F — gate-complete feasibility** (0–3, weighted ×4) | Does a genuinely local, authorizable path remain, and how small is the un-gated unresolved set? | 3 = local path with ≤4 un-gated rows, no freeze, no route conflict, fully tracked; 2 = local path with ≥5 un-gated rows or one scoped new test; 1 = mostly external gates, durability/untracked burden, clinical-approval dependency, or canonical-route conflict; 0 = no local path (gates-only), owner-frozen, or STOPPED |
| **H — PASS(E3+) achieved** (0–3) | Share of the tool's own applicable denominator already PASS(E3+) on the recorded figure. Denominators are not normalized across tools. | 3 = ≥80%; 2 = 40–79%; 1 = 1–39%; 0 = 0% |
| **L — locality / shared-edit exposure** (0–3) | Blast radius of the tool's own next change. P-03 is shared for all 29 and is **not** penalized here per W4b §4. | 3 = tool-local, clean tracked state; 2 = tool-local but untracked/modified artifacts must be preserved or scoped commit needed; 1 = extra shared-tool diagnosis (duplicate-box E4) or manifest/route-owner ruling; 0 = requires an unauthorized shared-component edit |
| **D — owner-decision blocker** (0–2) | Extra owner decision beyond the universal C4/C5/CLIN/W18 packets. | 2 = none beyond routine scoped authorization; 1 = additional owner/source/clinical/route decision; 0 = owner-frozen or STOPPED |

**Score = 4×F + H + L + D** (maximum 20). F carries the weight because gate-complete feasibility, not headline percentage, determines what can actually advance. Ties are broken by F descending, then H descending, then ascending tool ID. The `W3` comparison CSV is not present in `phase-next`; the 039 comparison action is therefore recorded as informational context only and is **not** a scored input. `OWNER-FROZEN` (041) and `STOPPED` (042) are hard-marked and excluded from actionable consideration regardless of score.
