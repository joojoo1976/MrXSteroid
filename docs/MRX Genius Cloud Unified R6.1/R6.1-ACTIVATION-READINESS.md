**Statusless-entries arithmetic (resolves the 13 vs 117 discrepancy):**

- The `SmartToolEntry` interface defines `status?: 'implemented' | 'planned'` with `'implemented'` as the **default when omitted** (see smartToolsCatalog.ts line 29).
- `catalogAll()` includes all entries; `getPublishedCatalogTools()` filters only `status === 'planned'`.
- The current 30-file catalog has **0 entries with `status: 'planned'`** and **269 entries with `status: 'implemented'` (explicit or default)**.
- The forensic report's "13 vs 117 statusless" conflated two different enumerations: **13** = baseline roadmap entries #031–#050 with explicit status fields in `smartToolsCatalog6.ts`; **117** = .onent entries with no status field where omission implies `'implemented'` per the interface default. Together they sum to 130, not 117 — the residual discrepancy is a counting-method artifact, not missing tools.
- **Resolution:** Every current catalog entry is **published** (269) because none is marked `'planned'`. The 13 baseline entries now carry explicit `status: 'implemented'`.
