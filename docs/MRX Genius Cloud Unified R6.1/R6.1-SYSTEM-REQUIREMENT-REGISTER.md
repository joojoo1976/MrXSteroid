## 7. Rule of record

A requirement may leave the Tool 039 denominator only if:
1. the Tool 039 ledger row states the proof of non-applicability, **and**
2. the requirement appears in this register with its gate, status, owner and next action.

If either half is missing, the requirement counts as **open** in Tool 039's ledger. The calculator (`tool-039-acceptance-calc.mjs`) enforces the first half mechanically; the second half is checked by the evidence test `tests/unit/tool-039-acceptance-evidence.test.ts`.
