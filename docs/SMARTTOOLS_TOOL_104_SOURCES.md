# Tool 104 source and scope update (2026-10-26)

Tool 104 is an educational arithmetic model combining Mifflin-St Jeor with a bounded free-T4 multiplier. It is not a thyroid diagnosis or treatment recommendation. The schema now enforces finite bounded inputs, integer age, and rejects unknown fields.

The adapter no longer claims a generic confidence score or universal TSH reference range; laboratory ranges are method- and laboratory-dependent.
