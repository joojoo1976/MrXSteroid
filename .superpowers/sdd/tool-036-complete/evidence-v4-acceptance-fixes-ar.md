## 6) ملحق الجولة 2 — تفصيل الأدلة (كله أُنتج في هذه الجلسة)

### 6.1 حدّ التسامح يُحكم على الدلتا الخام (لا على المعروض)
`lib/tools/tool-036-v4/engine/drift.test.ts` — 27/27، ومنه:
```
✓ an actual exactly AT the tolerance (+6h) is matched at the same site
✓ an actual 2 minutes PAST the tolerance (+6h02m) is late, δ = 6.03, chip and reason agree
✓ an actual well before tolerance but inside the window is still matched — earliness stated
✓ an actual within tolerance at the planned site is matched with a signed delta
✓ an actual later than tolerance but within 24h is late
✓ changing the declared tolerance changes only classifications, never numbers
```
القاعدة المعتمدة: التصنيف على `rawDeltaHours` غير المُقرَّب؛ والعرض `deltaHours` بمنزلتين
(`Math.round(x*100)/100`) مع حفظ الإشارة. لذلك `+6h` بالضبط → «مطابق» في الموقع نفسه، و`+6h02m` → «متأخر» ويُعرض 6.03،
و`−6h02m` داخل النافذة → «مطابق». (كان العيب: تقريب العرض يغيّر التصنيف، فيتناقض الرقم مع السبب.)

### 6.2 المطابقة المثلى (max-cardinality ثم min-total-cost)
ضمن `drift.test.ts` 27/27:
- `two overlapping windows claim two actuals without double-assignment`
- `among equal-cardinality matchings, the smaller total |delta| wins`

الطريقة: مسارات تعزيز قصيرة متتالية (Bellman–Ford على الشبكة المتبقية، تكاليف صحيحة بالملي ثانية، `<` صارم،
ترتيب ثابت للعقد والحواف) ⇒ نتيجة حتمية؛ وكسر التعادل: الجرعة الأسبق ثم الواقع الأسبق ثم المعرّف.
والعناصر الزائدة تحمل `scheduledAt: null` وتُعرض «بلا موعد مقابل».
