# 🔑 شرح تفصيلي: App Password Step-by-Step

## 📍 ما هو App Password؟

### التعريف البسيط:
```
App Password = كلمة مرور خاصة للتطبيق فقط
```

### لماذا نحتاجها؟
```
❌ Google لا تسمح باستخدام كلمة المرور العادية
   للتطبيقات الخارجية (مثل Supabase)

✓ Google تطلب App Password خاصة لكل تطبيق
```

### الفرق:
```
┌─────────────────────────────────────────┐
│  كلمة مرور Gmail العادية:               │
│  MyGmailPassword123                     │
│  ❌ لا تستخدمها مع Supabase             │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│  App Password:                          │
│  abcdefghijklmnop                       │
│  ✅ تستخدمها مع Supabase فقط            │
└─────────────────────────────────────────┘
```

## 🐛 المشاكل الشائعة

### المشكلة 1: "Select app" لا يظهر
```
السبب: 2-Step Verification غير مفعل
الحل: فعّل 2-Step Verification أولاً
```

### المشكلة 2: كلمة المرور لا تعمل
```
الأسباب:
1. استخدمت كلمة مرور Gmail العادية ❌
2. نسختها مع مسافات ❌
3. منتهية الصلاحية ❌

الحل:
1. استخدم App Password ✓
2. استخدمها بدون مسافات ✓
3. أنشئ واحدة جديدة ✓
```

### المشكلة 3: أغلقت النافذة قبل النسخ
```
الحل:
1. احذف القديمة (إذا ظهرت في القائمة)
2. اضغط "Generate new app password"
3. انسخ الجديدة فوراً
```
